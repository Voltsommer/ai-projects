# AI 应用作品集

用 Python + 大模型 API 从零搭建的 AI 应用系列，方向：**AI 应用开发 / 企业数据智能**。

全部项目共用一套技术栈：DeepSeek API + OpenAI SDK，逐步从命令行 → 网页界面 → 数据智能应用。

## 项目列表

| 目录 | 项目 | 亮点 |
|------|------|------|
| [01-学习助手](01-学习助手/) | 命令行 AI 学习助手 | 多轮对话 + 错误处理 |
| [02-网页学习助手](02-网页学习助手/) | 网页版 AI 学习助手 | Streamlit 聊天界面 |
| [03-数据问答助手](03-数据问答助手/) | 企业数据问答助手 | 数据质量 → 自然语言分析 → 受限执行 → 图表与审计 |

## 01 · 命令行 AI 学习助手

基于 DeepSeek API 的多轮对话助手。我的第一个 AI 应用。

- **连续对话**：自动维护对话历史，让模型记住上下文
- **角色设定**：通过 system 提示词定制 AI 人设
- **`/exit` 退出**：命令行交互支持退出命令
- **错误处理**：网络 / API 出错不崩溃，并自动清理对话历史中的残留消息
- 技术要点：`messages` 消息历史管理、`try / except / else` 区分成功与错误路径

```bash
pip install openai
export DEEPSEEK_API_KEY="你的key"
python 01-学习助手/main.py
```

## 02 · 网页版 AI 学习助手（Streamlit）

把命令行助手搬进浏览器，学会用 Streamlit 做聊天界面。

- `st.session_state` 保存对话历史（跨重跑保留）
- `st.chat_message` / `st.chat_input` 聊天组件
- `st.error` 界面内错误提示

```bash
pip install -r 02-网页学习助手/requirements.txt
export DEEPSEEK_API_KEY="你的key"
streamlit run 02-网页学习助手/app.py
```

## 03 · 企业数据问答助手（Streamlit）

**核心作品**：用自然语言问数据，AI 写代码（pandas / SQL）、Python 精确计算、自动出图表。支持**上传文件**和**连接数据库**两种数据来源。

- **两种数据来源**：上传 CSV / Excel，或直接连接 SQLite 数据库查询
- **数据接入质量检查**：上传前校验格式、体积与最大行数；分析前展示行列规模、缺失值、重复行和字段级质量明细，阻断空数据与重复字段名
- **自然语言提问** → AI 生成 pandas 代码（文件模式）或 SQL（数据库模式）→ 由程序执行计算，减少模型直接心算造成的数值幻觉
- **自动出图表**：类别 → 柱状图，月份 / 数字 → 折线图；多序列折线默认隐藏数值标签，普通点显示单点提示，近重合点使用局部汇总提示
- **可审计分析过程**：每次回答均可展开查看执行方式、AI 生成的 SQL / pandas 逻辑和结果预览；审计记录随对话持久化
- **分层执行防护**：SQL 经过只读查询白名单、SQLite 只读授权、超时和行数限制；pandas 代码经过输出清洗、AST 允许清单校验，并在原始数据的副本上受限执行
- **数据持久化**：对话文字、分析审计记录与上次上传的数据存本地，刷新页面后可恢复；结果预览最多保存 20 行，避免历史文件持续膨胀
- **故障降级**：缺少 API Key 时仍可只读浏览示例数据；聊天存档采用原子写入，损坏记录会隔离备份并自动恢复为空会话
- **运行可观测性**：使用隐私友好的 JSON Lines 日志记录分析状态、耗时、来源、结果规模和错误类别，不保存 API Key、问题正文或数据内容
- **自动化质量门禁**：离线测试覆盖数据接入、应用服务、执行器、图表、数据库、持久化与日志，并由 GitHub Actions 自动验证无密钥启动
- **模块化结构**：AI 服务、数据质量、安全执行器、审计记录和图表构建器相互独立，便于离线测试与后续替换
- 技术要点：NL2SQL / Text-to-Code 架构、提示词工程、SQL 分层执行防护、Python AST 校验、可审计分析链路、Streamlit 状态管理

```bash
pip install -r 03-数据问答助手/requirements.txt
export DEEPSEEK_API_KEY="你的key"

# 数据库模式首次打开时会自动生成示例库；也可手动重建
cd 03-数据问答助手 && python init_db.py

streamlit run 03-数据问答助手/app.py

# 离线运行全部自动化测试（不会调用 DeepSeek）
cd 03-数据问答助手
python -m unittest discover -s tests -v
```

项目内置 `.streamlit/config.toml`，统一限制上传文件为 10 MB，并在演示环境隐藏内部异常堆栈。运行时生成的聊天记录、上传数据、SQLite 文件和损坏记录备份均已排除在 Git 之外。

## 通用说明

- AI 对话功能需要 **DeepSeek API Key**，通过环境变量 `DEEPSEEK_API_KEY` 提供（不写死在代码里）；项目 03 未配置密钥时仍可只读浏览示例数据
- 环境变量设置：Windows PowerShell 用 `$env:DEEPSEEK_API_KEY="你的key"`，macOS/Linux 用 `export DEEPSEEK_API_KEY="你的key"`
- 示例数据：`03-数据问答助手/sample_data.csv`

> 安全说明：程序执行能提高数值计算的可靠性，但 AI 仍可能选错字段或聚合方式，因此“分析过程”会保留生成逻辑和结果预览供核对。AST 允许清单和受限 `exec` 属于作品集项目中的分层防护，不等同于进程隔离或操作系统级安全沙箱，不应直接用于执行不受信任用户提交的代码。
